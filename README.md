# CCLS

## Install

1. Clone project:
    ```bash
    git clone https://github.com/vuvoth/ccls/
    cd ccls/
    ```
2. Install Rust (if not install) via: https://www.rust-lang.org/tools/install
3. Now you can run test:
    ```bash
    cargo test
    ```
    or build ccls:
    ```
    cargo build
    ```
